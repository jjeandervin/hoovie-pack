# Fetch Quest sprites

Original placeholder pixel art, drawn on a 16 × 16 grid with crisp SVG rectangles/paths.
The dog sheet contains three horizontal frames: idle, left step, right step, facing down.
The renderer rotates the sheet for other directions. Tennis ball and treat are single tiles.
Replace these files (or update the renderer's image URLs/source frame sizes) to use final PNG artwork.
Grass and hedges are drawn on the canvas by GameRenderer.
